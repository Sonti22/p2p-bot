## Что сделано
- `backup.py`: раз в сутки копия `trades.db`, `blacklist.db`, `alerts.db`, `history.db`, `paper.db` (sqlite3 backup
  API — согласованный снимок, даже когда бот пишет) и `favorites.json`, `presets.json` в
  `data/backup/<ГГГГММДД-ЧЧММ>/`; хранится последних `BACKUP_KEEP` (7; 0 — выключено; мусор/минус — 7).
  «Пора ли» — по имени последней папки (переживает перезапуск). Копия пишется в `.tmp-…` и переименовывается только
  после успеха; сбой — временная папка удаляется, следующая попытка не раньше чем через час. Ротация удаляет только
  папки с именем по шаблону внутри data/backup.
- Не копируются: `keys.json` (секреты не размножаем), `snapshots.db` (гигабайты, восстанавливается сам), остальное —
  только явный список `FILES`.
- `Bot.schedule_backup` из `scan_loop` — фоном в отдельном потоке, параллельно вторая не идёт, ошибка — в лог.
- Тесты: `tests/test_db_backup.py` (5). ROADMAP: идея отмечена, строка в «Журнал».
