## Настройка HTTP

`HEALTH_CHECK_PORT=0` отключает listener; положительный порт включает его внутри bot.py. `HEALTH_CHECK_HOST` по умолчанию 127.0.0.1. Для внешнего адреса необходим HEALTH_CHECK_PASSWORD. Авторизация: заголовок Authorization со значением Bearer и паролем. `/status` показывает возраст скана, длительность работы и ошибки площадок; `/health` оценивает свежесть цикла сканирования, а не доступность каждой площадки. PROMETRICS=1 включает `/metrics`.

Самостоятельный запуск health_http.py не наблюдает работающий bot.py и остаётся неготовым: он не заменяет мониторинг внутри процесса бота.
