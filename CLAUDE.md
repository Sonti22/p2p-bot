# CLAUDE.md — P2P-бот сигналов

Telegram-бот: сканирует P2P-объявления за рубли (Bybit, MEXC, HTX, KuCoin, BitPapa) и обменники BestChange,
считает чистую прибыль связок с учётом комиссий и шлёт сигналы картинками с кнопками. Только чтение
публичных данных — бот не торгует и не трогает деньги.

## Файлы
- `p2p.py` — адаптеры площадок (`FETCHERS`), фильтры (`usable`, отсев аномалий `MAX_DEV`), расчёт маршрута
  (`_route`: комиссии вывода `WITHDRAW` по бирже/сети, спот `SPOT_FEES`, запас на курс `RISK_BUFFER`), `scan()`.
- `bot.py` — Telegram (long polling, без библиотек-обёрток): сигналы, меню, inline-кнопки, настройки → `.env`.
- `cards.py` — картинки на Pillow: карточка связки, график топа, аватарки.
- `.env.example` — все настройки с пояснениями; реальный `.env` в git не попадает.

## Запуск
```bash
pip install -r requirements.txt
python p2p.py      # разовый срез в консоль, без Telegram
python bot.py      # бот (нужен TG_TOKEN в .env)
python cards.py    # перерисовать аватарки
```

## Правила
- Python 3.10+, asyncio + aiohttp. Новая площадка = функция `(session, cfg, side, asset) -> list[Ad]` в `FETCHERS`.
- Эндпоинты бирж неофициальные: при изменении формата правится только адаптер.
- Интервал опроса не ниже ~10 с, не-USDT монеты — `ALT_INTERVAL`, BestChange — `BC_REFRESH` (бан по IP).
- Безопасность — не ослаблять: фильтры мерчантов, отсев аномальных цен, ручное подтверждение сделок.
  Не добавлять автоотпуск крипты, автоматизацию банковских приложений, обход капчи.
- Никогда не коммитить `.env`, токены, ключи API.
